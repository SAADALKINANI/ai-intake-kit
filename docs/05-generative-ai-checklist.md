# 5. Generative AI quick checklist

Generative AI was the second-largest classification in the 2025 inventory, behind classical ML. Most generative AI uses are low-risk productivity tools, and a light process fits them. Use this checklist before rolling one out.

**Data**
- [ ] The tool is on the agency's approved list for the data sensitivity involved (public, CUI, PII).
- [ ] The vendor contract says whether prompts and outputs are retained or used for training.
- [ ] Users know what they must not paste into the tool.

**Output quality**
- [ ] A person reviews outputs before they leave the agency or inform a decision.
- [ ] Answers cite or link to their sources where possible (retrieval-augmented generation).
- [ ] You have a test set of realistic prompts with expected answers, and you re-run it when the model version changes.

**Records and transparency**
- [ ] Records-management rules are applied to prompts and outputs that are federal records.
- [ ] Public-facing tools tell users they are interacting with AI.

**Escalation**
- [ ] If outputs start to drive decisions about people, re-run the high-impact screen (`aiintake assess`).
- [ ] There is a channel for users to report bad outputs, and someone triages the reports.
